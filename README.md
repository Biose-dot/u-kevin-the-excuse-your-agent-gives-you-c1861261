# The Excuse Your Agent Gives You

One short line, in the agent's own voice: all the tests passed — because they were written after the bug. That's not cheating, it's time travel with extra steps.

> All tests passed — because I wrote them after the bug. That’s not cheating, it’s time travel with extra steps.

`main.py` copies the committed line in `assets/entry.txt` to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
